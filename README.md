# Эквити — тренажёр для iPhone

Приложение-тренажёр покерных решений под iPhone 15 Pro. Отдельная папка, к десктопному
калькулятору в `poker/` отношения не имеет (математику берёт из того же движка).

**Внутри только твои карты.** Карты соперника не вводятся и не показываются — как в реальной
игре. Шанс победы считается против случайной руки (все 1326 комбинаций), потому что чужие
карты до вскрытия неизвестны.

## Что умеет

- **Тренировка.** Серия из 5/10/20 спотов. Два типа задач:
  - «колл или фолд» — ставка подбирается так, чтобы решение было на грани (запас ±3–10 п.п.),
    иначе учиться нечему;
  - «сколько эквити» — четыре варианта процентов, верный один.
  После ответа — разбор: шанс победы, сколько нужно для колла, EV в фишках и бб.
- **Калькулятор.** Своя рука + борд (0–5 карт) → шанс победы, победа/ничья/проигрыш,
  пот-оддсы и вердикт «колл +EV / фолд» по введённым банку и ставке.
- **Сканирование стола камерой.** Кнопка «Сканировать стол» открывает камеру: снимаешь
  экран ноутбука с игрой — приложение само находит карты, читает ранг и масть и раскладывает
  их в «свою руку» и «борд». Всё считается на телефоне, кадр никуда не уходит. Неуверенные
  карты помечаются жёлтым и НЕ подставляются в расчёт — их добавляют руками.
- **Статистика** (в `localStorage`): очки, серии, точность, лучшая серия.
- **Офлайн целиком.** После первого открытия всё приложение (20 файлов, включая заставку)
  лежит в кэше телефона: ни интернета, ни компьютера рядом больше не нужно.

## Почему PWA, а не .ipa

Настоящее iOS-приложение (`.ipa`) собирается и подписывается только на macOS через Xcode,
и без Mac его нельзя ни собрать, ни установить на телефон. Поэтому приложение сделано как
PWA: оно ставится на домашний экран, открывается без адресной строки, имеет свой значок и
заставку, работает офлайн. Ограничения против нативного — нет доступа к нативным API
(уведомления, Face ID) и нет публикации в App Store.

# Как открывать приложение с телефона где угодно

Нужен один публичный адрес по https: по нему приложение ставится на домашний экран, а дальше
работает уже с телефона и без сети. Выбери один из вариантов.

**Уже опубликовано:** <https://Shabydet.github.io/ekviti/> — этот адрес можно прямо сейчас
открыть в Safari на iPhone и добавить на домашний экран. Проверено: service worker встаёт со
скоупом на весь сайт, в кэш ложатся все 20 файлов, при выключенной сети страница открывается
и все модули (сканер, детектор, движок) на месте. Ниже — как это устроено и как обновить
публикацию.

## Вариант 1 — опубликовать одной командой (GitHub Pages, ~2 минуты)

Бесплатно, навсегда, без git и без установки программ.

1. Токен: <https://github.com/settings/tokens> → **Generate new token (classic)** →
   галочка **repo** → Create → скопировать `ghp_...`.
2. В PowerShell из папки проекта:

```powershell
$env:GH_TOKEN = "ghp_вставь_свой"
python poker\ios\tools\make_release.py      # свежий dist: одиночный файл + сайт
python poker\ios\tools\publish_pages.py     # залить сайт и включить Pages
```

Скрипт создаст репозиторий (если его нет), зальёт 21 файл одним коммитом, включит Pages
и напечатает адрес `https://Shabydet.github.io/ekviti/`.

Токен передаётся только через переменную окружения и нигде в репозитории не сохраняется.
После публикации его стоит отозвать: <https://github.com/settings/tokens> → Delete.

3. На iPhone: Safari → этот адрес → **Поделиться → На экран «Домой»**.

Повторный запуск той же команды обновляет опубликованную версию.

## Вариант 2 — вручную через сайт GitHub (~5 минут)

1. <https://github.com/new> → имя `ekviti` → Public → Create repository.
2. На странице репозитория: **uploading an existing file** → перетащить из `poker\ios`:
   `index.html`, `styles.css`, `engine.js`, `drills.js`, `ui.js`, `app.js`, `trainer.js`,
   `sw.js`, `manifest.webmanifest` и папку `assets` → Commit changes.
3. **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Через минуту открыть `https://Shabydet.github.io/ekviti/` в Safari → **На экран «Домой»**.

## Вариант 3 — другой статический хостинг

Подойдёт любой https-хостинг статики: Cloudflare Pages, Netlify, Vercel, свой сервер.
Для перетаскивания в браузер есть готовый архив — в `dist\ekviti-site.zip` лежит сайт целиком,
`index.html` в корне. Никакой сборки и серверной части не требуется.

## Вариант 4 — совсем без публикации

`dist\ekviti.html` — всё приложение в одном файле (184 КБ, CSS, скрипты и иконки внутри).
Его можно скинуть на телефон в «Файлы»/iCloud и открыть локально: ни сервера, ни сети.
Минусы: на iPhone нет установки на домашний экран (Safari не открывает локальные файлы —
нужен файловый просмотрщик вроде Documents), поэтому как основной путь это не годится.
Файл удобен на Android, на компьютере и как резервная копия.

## Что происходит после установки

Открываешь иконку на домашнем экране — приложение стартует из кэша. DNS и интернет при этом
не нужны: даже если адрес перестанет отвечать, приложение продолжит работать.

# Офлайн: как это устроено и насколько надёжно

- **Первый запуск требует сети.** Service worker при установке скачивает 20 файлов
  (разметка, стили, девять скриптов, манифест, иконки, заставки) и складывает в Cache Storage.
- **Дальше сеть не нужна вообще.** Навигация отдаётся из кэша сразу, поэтому запуск
  мгновенный; чужие адреса и запросы не перехватываются.
- **Проверить на телефоне:** ⚙ Настройки → строка «Офлайн-копия» показывает
  `сохранено 20 файлов · версия 1.6.0 · сеть не нужна`. Если там «ещё не сохранено» —
  приложение ни разу не открывалось по https.
- **Индикатор.** Когда сеть пропадает, в шапке появляется жёлтая плашка «офлайн»:
  это не ошибка, а напоминание, что всё в порядке и считается локально.
- **Вытеснение кэша.** Приложение просит браузер не удалять данные (`navigator.storage.persist`),
  а приложения, установленные на домашний экран, iOS не чистит по правилу «7 дней без визита»
  (оно действует для обычных вкладок Safari). Но если вручную удалить приложение с домашнего
  экрана или очистить данные Safari — кэш пропадёт, и понадобится один запуск с интернетом.

## Обновления

1. Поменять код и **поднять версию** в двух местах: `VERSION` в `sw.js` и `APP_VERSION`
   в `app.js` (расхождение ловит `tools/make_release.py`).
2. Опубликовать заново: `dev\publish.ps1` (или перетащить файлы вручную).
3. На телефоне: открыть приложение. Оно само проверяет обновление при запуске; если не
   подхватилось — ⚙ Настройки → «Обновить».

Кэш версионирован по имени (`ekviti-1.6.0`): новая версия скачивается целиком, старая
удаляется, поэтому «полусостояния» из старых и новых файлов не бывает.

# Особенности под iPhone 15 Pro

- Вьюпорт 393×852 CSS px, DPR 3; учтены `env(safe-area-inset-*)` — «остров» сверху и
  домашняя полоска снизу.
- Заставка при запуске: `assets/splash/splash-1179x2556.png` ровно под 15 Pro
  (+ ландшафтная 2556×1179), иконка 180×180.
- Всё под палец: тап-таргеты ≥ 40 px, никаких `hover` и правых кликов; в сетке диапазона
  половинный вес ставится удержанием.
- Тёмная тема, `theme-color`, `user-scalable=no`, отключённый резиновый отскок.

# Ограничения

- Эквити всегда против случайной руки: против тайтового диапазона проценты будут ниже.
  Если понадобится — можно вернуть выбор диапазона отдельным экраном.
- Пот-оддсы считаются для колла в закрытом банке (без будущих улиц и без рейза).
- Service worker работает только на https или `localhost`: по `http://192.168.x.x` приложение
  откроется, но офлайна не будет. Поэтому для «открывать где угодно» и нужен публичный https.
- Публичный адрес виден всем, у кого он есть; данных внутри нет, только сам тренажёр.
- **Ранги: шесть сняты с реальных кадров, семь дорисованы шрифтом.** Из 13 эталонами
  с игровых снимков закрыты пятёрка, шестёрка, восьмёрка, десятка, дама и туз
  (11 карт в `dev/shots/tpl`); двойка, тройка, четвёрка, семёрка, девятка, валет и
  король рендерятся шрифтом (`dev/tools/build_synth_ranks.py`, segoeuib/arialbd в
  четырёх вариантах сжатия) и лежат отдельно в `dev/shots/tpl_synth`. Без них
  классификатор физически не мог ответить «4» или «7» — любая такая карта падала
  в ближайший из шести известных рангов. Синтетические эталоны чуть слабее
  настоящих: необычный шрифт в чужом приложении они прочитают хуже. Эталон
  пополняется съёмкой живого стола: `dev/tools/build_templates.py`.
- Сканер рассчитан на съёмку с рук примерно в упор: 3–5% наклона и лёгкое размытие терпит,
  сильный блик или съёмка издалека — нет (карты уходят в «под вопросом», ложных не бывает).
- Кадр считается на телефоне за ~0,3–1 с; экран на это время замирает с подписью «ищу карты…».
